# OWASP-Juice-Shop-Security-Assessment
### Web application security assessment of OWASP Juice Shop involving vulnerability analysis, SAST, DAST, JWT testing and remediation recommendations.

## Overview
### This project involved conducting a security assessment of the OWASP Juice Shop vulnerable web application as part of the Web Application Security module.

## Objectives
#### ◦ Identify and analyse security vulnerabilities
#### ◦ Perform static and dynamic security testing
#### ◦ Investigate authentication weaknesses
#### ◦ Produce remediation recommendations

## Technologies & Tools
#### ◦ OWASP ZAP
#### ◦ Burp Suite
#### ◦ JWT.io
#### ◦ CyberChef
#### ◦ Semgrep
#### ◦ Kali Linux

## My Contribution
#### ◦ Analysed JWT authentication weaknesses
#### ◦ Investigated null-byte injection vulnerabilities
#### ◦ Identified sensitive data exposure issues
#### ◦ Participated in SAST and DAST testing
#### ◦ Produced technical documentation and remediation recommendations
